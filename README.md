# LeadPro

LeadPro is a lead processing system that compiles messy database values into a custom lightweight Obsidian CRM.

## Description

I've built a simple CRM in Obsidian using Dataviews where I compile each lead into individual notes with enriched information such as:
- Contact Information  
- Date & Time of Last Contact
- Follow Up Date
- Cold / Warm
- Source of Lead
- Value Potential
- Website Quality (I sell web infrastructure)
- Etc

This streamlines the cold outreach process by making messy databses easily accessible and data visualisation easy for each business. It's highly customisable as the architecture is so that mapping values are customizable and Dataviews allows you to easily create tables for different purposes. 

For example, my "Overview" CRM dashboard lists all values within every note in a specified path in one easy-to-viewtable.

The issue with creating lead lists here is that it takes way too long - enrichment, simple processing - it was taking me around 10 mins per lead, which is not efficient at all.

To speed things up, I built this system. Now I can use software scrapers to compile databases on a targeted ICP, export a couple lists of leads (starting with the best ones first) and run this script to instantly have a clear viewof who I'm targeting in an easy & contextual customer relation management system.
